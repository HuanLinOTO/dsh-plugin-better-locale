- **RC1-01 命中**：`package.json:49` peer `@deepseek-ai/dsh-client-locale` 原为 `^0.1.5-rc.2`；0.1.7 在启动时按精确版本强制兼容，必须提升到 `^0.1.7-rc.1`（prerelease 同 tuple 范围可满足 `0.1.7-rc.1`；精确 pin 会不满足）。`@deepseek-ai/cordis` 保持 `^4.0.1` 不动。
- **RC1-33 命中（词典 key/文案）**：本插件是 DSH 内置 locale namespace 的第三方翻译副本（19 种语言），上游 UI 文案变更会通过 `src/client/upstream-coverage.ts` 的 drift/trespass 守卫暴露。RC1-33 使 `ui-workspace` 的会话行动作从命令式方法变为 slot list，本地化 key 面变化：
  - 新增（drift，词典需补）：`workspace.menu.fork`、`workspace.menu.archiveSession`、`workspace.menu.unarchiveSession`、`workspace.menu.pinSession`、`workspace.menu.unpinSession`、`workspace.actions.{archive,unarchive,pin,unpin,newSession}`、`workspace.archive.confirm.*`、`workspace.toast.archived*`/`pinFailed`/`unpinFailed` 等。
  - 移出（trespass，词典需删）：旧的 `workspace.search.unavailable`（以及同批被上游改名的会话菜单/状态文案）。
- **`settings.plugin.item` / `settingsScope` 非命中**：`rg` 两词在本插件 src 中均无命中——插件不发设置页、不绑定配置，语言选择由 DSH 自带 Language 行完成，无可迁移面。

## 行动

1. **RC1-01**：`package.json` peer `@deepseek-ai/dsh-client-locale` `^0.1.5-rc.2` → `^0.1.7-rc.1`（仅此一处；`@deepseek-ai/cordis` 保持 `^4.0.1`）。
2. **RC1-33 / 词典对账**：以 registry `0.1.7-rc.1` 类型树为基准跑 drift 分析，结果见下；**整批词典对账（498 个新增 key + 每语言 123 个失配 key × 19 语言）标记 pending review**——这是数千条翻译，属于独立的 i18n 批量工作，不适合在低置信度下自动机翻。本次不新增 `upstream-coverage.ts` 的 import（新增 `ui-plugin-manager`/`ui-sidebar-terminal` 等 merge 模块会立刻破坏本仓库当前指向 0.1.5-rc.2 checkout 的 `pnpm typecheck`，该 import 列表更新属于「checkout 升到 0.1.7」那一步）。
